# AI Design with Precision

Five password-protected lessons on precise visual prompting and album cover design.

https://unibiubiu.github.io/videos-and-reading/ai-design-with-precision/

Video and attachment files are encrypted with AES-256-GCM. The browser derives the decryption key from the supplied course password using PBKDF2-SHA256 (600,000 iterations and a random salt). The password and key are not stored in this repository. Access is cleared when the page closes or the learner selects Lock access.

The public Reading page links to original reference sources. Classroom guides are available after unlocking the matching tutorial. Original 4K masters remain in the instructor’s local course folder; web playback is 1080p.
